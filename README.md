# 稽古堂 · 公版文本注释版编辑工具

面向公版古籍整理者的章节、句子和词语级注释工作台。支持脚注、异文、背景说明与交叉引用，并可在阅读版、编辑版、校勘版之间切换，解决不同来源之间的注释冲突。

## 功能

- 按章节、句子和词语选择注释目标，维护脚注、异文、背景说明和交叉引用。
- 使用稳定 ID 保存正文与注释关系；句子修订后，失效的词级引用自动迁移到所属句，避免悬空引用。
- 自动按“引用目标 + 注释类型”汇总来源冲突，可逐条选用来源或合并正文后解决。
- 阅读版按引用展开脚注，编辑版提供正文和注释编辑，校勘版并列展示来源、异文与校记。
- 章节目录跳转、正文/注释/来源全文检索，以及下一条注释快速定位。
- 本地离线草稿自动保存；模拟接口保存按钮用于演示网络保存状态。
- 版本快照与两版差异比较，可查看句子改动、新增注释并恢复快照。
- 两台机器离线三向合并：以共同校订快照为基准重新定位句子与词语；唯一对上的注释沿用，原词消失（或同形词无法唯一定位）时自动迁到所属句。
- 合并冲突并列保留：同一条注释两边都改、互见关系不同、一方删除一方修改、同句两边都有校改时，逐条选择甲稿/乙稿/并列两条，全部裁决后才写入当前稿。
- 多标签页并发保存同一旧底本：草稿带版本号，后保存者检测到对方保存后自动做三向合并，保留对方修改并提示重载；句子取对方版本、注释冲突进入待处理项。
- 合并事务化：裁决前不改当前稿；合并失败自动恢复原草稿与待处理项。已确认的合并结果留存，可一键恢复合并前草稿；合并写入、恢复、导出读取同一份确认结果，未裁决时禁止导出。
- 导出完整 HTML 阅读版或 JSON 数据，支持浏览器打印。
- 快捷键：`J/K` 上/下一条注释，`[`/`]` 上/下句，`/` 聚焦搜索，`Alt+1/2/3` 切换视图，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做，`Ctrl/⌘+S` 模拟接口保存。
- 响应式布局：桌面使用三栏工作区，窄屏自动堆叠；所有主要按钮和编辑目标均有语义标签。

## 技术栈

- Next.js 15（App Router、静态导出）
- React 19
- TypeScript
- HeroUI + Tailwind CSS
- localStorage 离线持久化
- 浏览器内模拟接口，无后端依赖

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的本地地址。开发服务器端口由 Next.js 决定，源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `out/`。由于启用了 `output: 'export'`，不需要 Node.js 服务即可托管。

## Docker

```bash
docker build -t sologsb-1022 .
docker run --rm -p 10022:80 sologsb-1022
```

容器内 nginx 监听 `80`，根端口表将其映射为宿主 `10022`。

## 数据说明

离线草稿（含版本号）、合并待处理项、已确认的合并结果以及最后编辑位置保存在当前浏览器 `localStorage`。清除站点数据会删除这些内容；导出的 HTML/JSON 可用于外部备份。

## 两台机器离线合并

1. 出发前两边先在“版本”标签页保存同一份**校订快照**（基准快照）。
2. 各自离线校勘；回来后在乙稿机器“版本”页导出 JSON。
3. 在甲稿“合并”标签页选择共同快照、导入乙稿 JSON，点“按快照重新定位并试合并”。
4. 查看自动处理明细；并列保留的句子正文与注释逐条选择（甲稿 / 乙稿 / 并列两条）。
5. 全部裁决后点“确认并写入当前稿”；如要退回，用“恢复原草稿与待处理项”回滚到合并前。

## 多标签页并发

同一浏览器打开两个标签页编辑同一旧底本时，后保存者（手动保存或自动保存检测到版本号落后）会自动三向合并对方修改并提示重载；无法合并时绝不覆盖，原草稿与待处理项原样保留。

## 测试

```bash
npm run test:merge
```
